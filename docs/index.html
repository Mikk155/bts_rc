01 / THE BRIEFING

This is not a routine drill.

Black Mesa has prepared a restricted training simulation based on a resonance cascade. You have been assigned to Sector H. The facility is vast, the situation is unpredictable, and your team will need more than firepower to make it through.

Search the complex, pay attention to signs and environmental clues, and learn how its rooms and routes connect. The simulation rewards teamwork and careful exploration.

Read the map briefing on SC Map Database ↗

02 / WHAT TO EXPECT

Explore. Scavenge. Stay together.

Every corridor is part of a larger facility. Take your time, share what you find, and adapt when the plan changes.

A

A facility to learn

Explore labs, living quarters, service spaces, and connecting routes. Signs, maps, and details in the environment can help point your team in the right direction.

B

Scavenge and manage

Weapons, supplies, and important objects use an inventory system. Finding an item is only the first step: keep track of it and activate it when you need it.

C

Expect a different run

Many monsters, weapons, and supplies can appear in different places between playthroughs. Share discoveries and be ready to improvise.

D

Play as a team

Choose a character classification, communicate about useful finds, and support one another. A teammate's spare supplies may matter more than another weapon.

The experience is designed as a challenging survival map. New players may need more than one attempt to learn its layout and systems.

04 / BEFORE YOU DEPLOY

Your first visit?

A few simple pointers make the opening minutes easier.

01

Get the map files

Use the map page for the current download and installation notes. The map runs in Sven Co-op.

02

Join a co-op session

Find a server running bts_rc, or ask your group to host it. A team makes exploration and inventory management easier.

03

Learn how items work

Pickups may go into your inventory instead of being equipped immediately. Open your inventory and activate what you want to use.

04

Keep your bearings

Read signs, look for maps and clues, and communicate with your team. If you get stuck, regroup and retrace your route.

OPTIONAL / CONTRIBUTORSContribute to the project+

Contributions are welcome. The project includes map scripts, custom entities, gameplay systems, and automation tools.

Before opening a pull request, read the detailed contribution guidelines and run the project's checks. Repository details and technical documentation are available in the source repository.

Install or update the project

Clone the repository into the Sven Co-op installation.

Clone the project
git clone --recurse-submodules https://github.com/Mikk155/bts_rc svencoop_event_bts

If it's been already cloned without "--recurse-submodules" make sure its submodules are initialized.

Initialize existing submodules
git submodule update --init --recursive

Install assets

Install the assets from MEGA or sync the folder to svencoop_event_bts/

MEGA ↗

Check the event in Sven Co-op

Use the client console to check whether the event is detected. If needed, enable it by its event name:

Check and enable the event
ev_list
ev_enable bts
OPTIONAL / SERVER CONFIGURATIONBuild a bts_rc configuration file+

Add complete sections to your configuration. Each section starts with the repository's default values; you can then edit the generated JSON if needed. When downloading bts_rc.json place it in svencoop/scripts/maps/store/ for the map scripts to parse it.
